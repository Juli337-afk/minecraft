
# Instrucciones para Clonar y Actualizar el Repositorio

## Clonar el repositorio

```bash
git clone https://github.com/Juli337-afk/minecraft.git
```

## Actualizar repositorio local (¡SIEMPRE ACTUALIZAR ANTES DE SUBIR CAMBIOS!)

```bash
git pull
```

## Subir cambios al repositorio remoto

```bash
git add .
git commit -m "nombre_commit"
git push
```
